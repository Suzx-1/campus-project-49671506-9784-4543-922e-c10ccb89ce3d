# 停哪儿 · 校园停车记录

## 简化版界面

定位已增加严格门槛：持续请求高精度实时位置，最多等待 45 秒；只有有效、新鲜（10 秒以内）且设备报告 accuracy 在 (0,20] 米的位置可保存。不再提供忽略精度强行保存选项。超时、拒绝权限、取消定位均不覆盖原记录。常用地点不满足同样精度要求也不能复用为新的停车记录，需现场重新定位。设备报告的估计误差不是实际误差保证，网页无法控制手机 GPS 硬件；需开启系统及浏览器“精确位置”。

当前入口使用 `parking-simple.js` 与 `simple.css`。首页只显示“直接定位”、历史记录、常用地点、找车，不要求填写停车资料。点击“直接定位”后获取当前坐标并保存时间；定位误差超过 100 米时先提示确认。定位失败不新增记录。

新定位会把之前未结束的记录转入历史；原有记录、常用地点与照片仍保留。常用地点从找车页面收藏，只需起一个名称。找车页支持地图导航、距离方向和确认取车。

下方为旧版功能说明，简化版不再提供停车表单；旧源文件仅供参考。

从校园工坊的“运行与预览”启动，不需要安装依赖。

## 使用

1. 停车时点击“记录停车位置”。填写地点、校区和附近标志，可添加照片，也可在浏览器授权后点击定位。
2. 下课后查看当前停车位置。点击“导航去找车”，选择高德或百度，联网打开步行导航。
3. 没有坐标时打开地点搜索，车棚排数等细节依靠手动备注和照片寻找。
4. 取车后点击“我已取车”，记录仍保留在停车历史。
5. 将常去的车棚保存到“常用地点”，下次点击“停在这里”直接复用说明。

## 边界

- 当前是电脑本地网页，不会在关闭页面后自动发现停车行为，不获取实时空位。
- 桌面浏览器定位精度可能较低，可能需要网络提供位置服务。定位失败时手动记录仍可用。只有点击定位才请求位置。
- 经纬度采用 GPS/WGS84；不要直接填入已偏移的高德/百度坐标。地图路线取决于外部服务，校园内小路需结合现场。
- 每种车辆类型保留一个当前停车位置。再记同类车辆的新位置，旧记录会转为“已更新位置”的历史。不同类型车辆可同时记录。
- 多窗口同时修改时，旧窗口会提示刷新，避免覆盖新记录。

## 数据保存

记录和压缩照片通过本地服务写入此项目目录中的 `.campus-storage.json`，与预览端口无关。刷新、关闭网页和重启工坊后仍可读取。

工坊的完整备份包含这个数据文件。停车历史页也支持单独导出记录供查阅；恢复整个工作空间请使用工坊的完整备份功能。源文件导出、项目副本也会包含此文件；如果需要向他人分享纯代码，请先从导出文件中移除 `.campus-storage.json`。

外部地图只会在点击相应链接后打开，目的地会传给该地图服务。不会上传其他停车历史。
